We've added a [stats page](/stats).

It's where the project's numbers live: total sightings, total unique Oceans, contributor leaderboard, first-sighting rate over time, and whatever else seems worth charting. If you've ever wondered where you sit on the leaderboard, or how the catalog is filling in week-over-week, this is the page for that.

A few things worth checking out:

- **Contributor leaderboard** — sightings, first sightings
- **Progress over time** — how the catalog has filled in since launch.

This pairs nicely with the [badges page](/badges), which shows which [Badges](/p/what-are-badges) each contributor has earned (and which they're still chasing).

If there's a number you'd like to see and we're not surfacing it yet, let us know.
